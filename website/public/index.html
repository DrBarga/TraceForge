Process identity matters.

A watch holds the process handle. Start-time checks protect reconnection from attaching to a different process that reused the same PID.

Collection can fail.

Availability flags and Win32 error codes travel with the measurements. Protected processes can return partial data.

The agent can restart.

Each app instance has a separate agent and pipe. Requests have timeouts; the app reconnects after communication failures.

Read before using 1.0.0

  • The executables are unsigned. A checksum verifies archive integrity, not the publisher.
  • One process can be watched at a time. Very short-lived applications may exit before the watch attaches.
  • Automatic crash dumps, hang detection, symbol resolution and Windows Error Reporting correlation are outside this release.
  • Ordinary diagnostics use your current Windows permissions. The app does not automatically elevate or install a service.
