BEFORE YOU INSTALL

A few practical details.

Does it need administrator rights?

Ordinary diagnostics run with your Windows account's existing permissions. Protected or elevated processes may return partial data. TraceForge does not automatically elevate or install a service.

What is inside a report?

The JSON includes the current process inventory, a sampled timeline, anomaly flags, and available incident and inspection data. HTML presents a summary. Reports can include other processes on the machine. Read the data-handling brief before sharing them.

Is the executable signed?

No. The 1.0.0 portable release is unsigned and has no installer. Windows may show a publisher warning. The supplied SHA-256 checks archive integrity; it does not replace a publisher signature.

Is this a crash debugger?

TraceForge captures process context and observed exits. You can request a MiniDump manually. Automatic crash-time dumps, hang detection, symbol resolution, and Windows Error Reporting correlation are outside the 1.0.0 scope.

Does this website collect analytics?

This site has no analytics scripts, tracking cookies, external fonts, or contact form. Vercel can process normal hosting request logs. GitHub handles download requests, and email is handled by your mail provider.
